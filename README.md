# 📖 Okuttur

**Okuttur**, favori web novel içeriklerinizi keşfetmeniz, organize etmeniz ve kesintisiz bir şekilde okumanız için geliştirilmiş modern bir web platformudur. Minimalist tasarımı ve kullanıcı dostu arayüzü ile okuma deneyiminizi bir üst seviyeye taşır.

## ✨ Özellikler
 * **Modern Arayüz:** Google'ın Material Design standartlarına uygun, temiz ve akıcı kullanıcı deneyimi.
 * **Geniş Arşiv:** Binlerce web novel içeriğine hızlı erişim ve kolay arama.
 * **Çevrimdışı Okuma:** Bölümleri cihazınıza **indirme özelliği** sayesinde internetiniz olmasa bile okumaya devam edin.
 * **Kişiselleştirilebilir Okuyucu:** Yazı boyutu, tema (gece/gündüz modu) ve font ayarlarıyla size özel okuma alanı.
 * **Kütüphane Yönetimi:** Okuduğunuz serileri takip edin, kaldığınız yeri otomatik kaydedin.

## 🚀 Teknolojiler
Bu proje, hız ve estetiği bir araya getirmek için aşağıdaki teknolojilerle güçlendirilmiştir:
 * **React** - Kullanıcı arayüzü kütüphanesi.
 * **Material UI (MUI)** - Modern ve özelleştirilebilir bileşen kütüphanesi.
 * **React Router** - Sayfalar arası akıcı geçişler.
 * **Local / Web Storage** - İndirilen içeriklerin ve kullanıcı tercihlerinin saklanması.
